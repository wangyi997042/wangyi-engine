# Engine 模块 README
## 一、模块概述
`engine` 是整个前端项目的**核心引擎模块**，承担组件渲染、数据联动、模板解析、通用工具封装等核心能力，是连接业务配置与页面渲染的核心层。该模块基于 Vue3/React + TypeScript 开发，遵循“高内聚、低耦合”的设计原则，适配多端（PC/移动端/微信环境）、多场景（表单联动、动态组件渲染）的业务需求，为上层业务提供稳定、可扩展的底层支撑。

## 二、核心功能
1. **动态组件渲染**：解析组件配置，从上下文获取映射关系，动态渲染对应组件并传递属性；
2. **组件联动逻辑**：处理组件的隐藏/显示/更新/重置/动作执行等联动规则，支持表达式解析与状态实时更新；
3. **通用工具封装**：提供类型判断、深拷贝、URL解析、环境检测、异步控制等全项目复用的工具函数；
4. **模板解析与渲染**：解析HTML模板、处理数据绑定与换行适配，完成动态模板的渲染；
5. **跨环境适配**：兼容浏览器/Node、移动端/PC、微信/普通浏览器等不同运行环境；
6. **数据处理与安全**：封装路径解析、对象操作、数据隔离（深拷贝）等逻辑，保证数据操作的安全性。

## 三、实现难点
1. **联动逻辑的多场景兼容**：需兼容 `hidden/visible/update/replace/reset/action` 等多类型联动规则，同时处理“单值/数组配置”“表达式解析结果异常”“数据污染”等边缘场景，平衡逻辑复杂度与可维护性；
2. **类型安全与灵活性平衡**：既要通过 TypeScript 接口/泛型约束核心数据结构（如联动配置、组件属性），又要适配业务侧灵活的自定义配置，避免过度类型约束导致扩展性下降；
3. **跨环境适配的完整性**：需兼容不同浏览器、设备、运行环境（如微信小程序SDK加载、history路由/普通跳转适配），处理环境API缺失、兼容性差异等问题；
4. **性能与鲁棒性兼顾**：在保证“空值兜底、异常降级、数据隔离”等鲁棒性设计的同时，避免深拷贝、重复表达式解析等操作带来的性能损耗；
5. **工程化协同适配**：需兼容 Umi 等构建工具自动生成的代码，区分“手动维护代码”与“自动生成代码”，避免破坏工程化构建流程。

## 四、核心亮点
### 1. 模块化设计，职责边界清晰
遵循“单一职责原则”，将不同功能拆分为独立文件/函数：
- 路径解析仅在 `helper.ts` 中实现；
- 联动逻辑仅在 `cascade.ts` 中维护；
- 通用工具仅在 `tools.ts` 中封装；
- 组件渲染仅在 `dataRender.tsx` 中处理；
模块间低耦合，可独立修改、测试、复用。

### 2. TypeScript 驱动，类型安全兜底
- 通过接口（`IWidgetData`/`ICascadeOn`/`UrlProps`）约束核心数据结构，避免运行时类型错误；
- 泛型（如 `ComponentRender<P, N>`）适配通用组件渲染场景，提升代码复用性；
- 类型守卫（`isObject`/`arrayHasChild`）缩小类型范围，减少类型断言，提升代码可读性。

### 3. 防御式编程，鲁棒性拉满
- 空值兜底：`const { dataBind } = data || {}` 避免解构报错；
- 类型校验前置：非对象类型的联动配置直接跳过，避免后续逻辑崩溃；
- 数据隔离：深拷贝默认数据避免源数据污染；
- 异常降级：`historyPush` 失败时降级为 `location.href` 跳转，SDK加载失败时友好处理。

### 4. 通用逻辑抽象，复用性高
- 抽离 `resolvePath`（路径解析）、`assignObj`（对象合并）、`deepCopy`（深拷贝）等通用函数，避免重复代码；
- 联动逻辑中统一处理“表达式解析→结果判断→状态更新”流程，不同联动类型复用核心逻辑。

### 5. 多环境适配，通用性强
- 封装 `isMobile`/`isInWechat`/`parserBrowser` 等环境检测函数，业务侧可直接复用；
- 工具函数兼容浏览器/Node 环境（如 `root` 变量兜底），适配 UMD 打包格式。

```
├── types.tsx // 引擎全局类型：定义跨模块的通用类型（如全局上下文、通用对象、URL 参数），扩展 Window 类型（如全局引擎变量）
```

## 六、总结
`engine` 模块是项目的“底层发动机”，通过模块化设计、类型安全、防御式编程、通用逻辑抽象等设计思路，实现了“稳定、可扩展、高复用”的核心目标。该模块不仅支撑了当前项目的组件渲染、联动等核心业务，其设计思想（单一职责、DRY原则、防御式编程）也可复用于其他前端项目的底层引擎开发。
